# Чертежи AutoCAD по ГОСТ/СПДС (коннектор 1.7+)

Строительные чертежи (КЖ, КМ, АР, фундаменты, геология, схемы к ПЗ) в живом AutoCAD через **AutoCAD MCP Pro 1.7+** (форк с пакетом `spds`, 10 инструментов).

Нормативная база: ГОСТ Р 21.101-2020, ГОСТ 2.301–2.307, ГОСТ 21.302-2013. Требования кафедры или руководителя важнее; о расхождениях с ГОСТ сообщай пользователю.

> Если в коннекторе нет инструментов `spds_*` (версия до 1.7), этот скилл не подходит: нужна прежняя версия с библиотекой AutoLISP.

## 1. Настройка коннектора (один раз)

В конфиге MCP-сервера задать `TOOL_CONFIG=spds`. Что это даёт:
- в списке ~70 инструментов вместо 252, с короткими описаниями (≈ 8,6 тыс. токенов вместо ≈ 62 тыс.);
- остальные инструменты доступны через `search_tools` → `call_tool`, по-русски тоже: «круговой массив», «сохранить в pdf»;
- полное описание любого инструмента возвращает `tool_help(name)`;
- создающие инструменты возвращают только `{handle, type}`.

## 2. Экономный порядок работы

1. `system_status` — что открыто и нет ли несохранённых правок пользователя.
2. Новый чертёж: `drawing_new(template="gost_a3_spds")`. В нём уже всё из п. 3 (стили 1:50 / 1:100 / 1:200, текущий 1:100) и вкладка «Лист1» с рамкой А3, пустой формой 3 и полем подшивки; графы заполнить через `spds_sheet_update`. Пустой чертёж: `drawing_new(bootstrap=false)`. Чужой чертёж: `drawing_understand` или `drawing_digest`, а не `entity_list` целиком.
3. `spds_setup(scales=[100, 50], current_scale=100)` создаёт:
   - типы линий GOST_DASH / GOST_AXIS / GOST_2DOT;
   - слои Контур / Тонкие / Невидимые / Оси / Размеры / Отметки / Выноски / Текст / Штриховка;
   - стиль текста GOST (isocpeur.ttf);
   - размерные стили `СПДС_1-M`;
   - MEASUREMENT=1 (метрические образцы штриховок: в чертеже из acad.dwt штриховка иначе в 25,4 раза гуще).

   Повторный вызов безопасен: созданное не дублируется. То же одним словом: `drawing_apply_standard("gost", scale=M)` (ещё делает текущими `СПДС_1-M` и стиль GOST).
4. Перед этапом `drawing_checkpoint()`, после него `drawing_diff_since()`: только изменения, по строке на объект.
5. Серии однотипных операций выполнять одним `cad_batch`.
6. Перед сдачей `drawing_digest(frame=[...], text_heights=[2.5·M, 3.5·M, 5·M, 7·M])` покажет:
   - незамкнутые контуры;
   - объекты за рамкой;
   - дубликаты;
   - высоты текста вне ряда.
7. `drawing_critique(focus=None)` перед сдачей: шесть фокусов `spds_*` (раздел 6а) проверяют то, что нарисовано пакетом.
8. Скриншот только в конце этапа: `view_screenshot(window=[x1,y1,x2,y2], width=800, mode="mono")`. Окно задаётся в координатах чертежа, вид пользователя не сдвигается. Стоит ≈ 300–600 токенов.

## 3. Схемы построения модели

**А. Натура 1:1 в мм + лист** (планы, опалубка, узлы). Геометрия в реальных мм.
- Марки и тексты: `scale=M` в `spds_*` (рисуются в мм бумаги × M).
- Размеры: `dimension_*(..., dimstyle="СПДС_1-M", layer="Размеры")`.
- На листе: `viewport_create(..., scale=1/M, remove_others=True, layer="Defpoints")` → `viewport_lock`. Слой Defpoints не печатается, рамка видового экрана в PDF не попадёт.

**Б. «Мм бумаги»** (геологический разрез с Мг ≠ Мв, схемы к ПЗ). Пересчёт координат:
- x = L·1000/Mг;
- y = (H − H0)·1000/Mв.

`scale=1`. Размеры с реальными метрами — через `text_override`.

## 4. Инструменты пакета spds

| Задача | Вызов |
|---|---|
| Лист со штампом формы 3 (А4 книжный, А3) | `layout_create("Лист1")` → `spds_sheet(format="A3", layout="Лист1", stamp={...}, signatures=[["Разраб.","Иванов","10.26"], ["Пров.","Петров",""]], extra_columns=false)` |
| Поправить штамп (номер листа, наименование) | `spds_sheet_update(stamp={"sheet": "2", "sheet_title": "План"}, layout="Лист2")`: меняет только эти графы, лист не перерисовывает; `""` очищает графу |
| Графы штампа (`stamp`) | `code` (1, шифр), `project` (2), `building` (3), `sheet_title` (4), `stage` (6), `sheet` (7), `sheets` (8, только на первом листе), `organisation` (9) |
| Координационные оси плана | `spds_axis_grid(xs=[...], ys=[...], scale=M)`: цифры по стороне с бо́льшим числом осей, буквы без Ё З Й О Х Ц Ч Щ Ъ Ы Ь, марки снизу и слева |
| Одна ось | `spds_axis(x1,y1,x2,y2, mark="1", ends="start"\|"end"\|"both", scale=M)` |
| Отметка на разрезе/фасаде | `spds_elevation(x, y, value=-1.65, scale=M)` → «-1,650»; ноль без знака, «+» выше нуля |
| Отметка на плане | `spds_elevation(..., kind="plan")`, текст в прямоугольнике |
| Абсолютная отметка | `spds_elevation(..., value=160.65, decimals=2, signed=false)` |
| Выноска | `spds_leader(points=[[цель],[начало полки]], text="Бетон В25", text_below="F150 W6", end="dot"\|"arrow"\|"none", scale=M)`: `dot` внутри контура, `arrow` на линии контура |
| Линия разреза 1–1 | `spds_section_mark(x1,y1,x2,y2, label="1", side=1\|-1, scale=M)`: штрихи 0,7, стрелки взгляда, марки |
| Уклон | `spds_slope(x, y, value=0.005, kind="section"\|"plan", direction=1\|-1, as_percent=false, scale=M)` |
| Грунты (ГОСТ 21.302) | `spds_soil_hatch(boundary=[[x,y],...], soil="суглинок"\|"супесь"\|"глина"\|"насыпной"\|"песок", grade="средний", label_at=[x,y], scale=M)`; для песка буква Г/К/С/М/П в кружке |
| Текст стилем GOST по центру | `entity_create_text(..., style="GOST", align="MC", width_factor=0.9)` |
| Продлить ось или шурф «до низа» | `entity_edit_geometry(handle, vertex_index=-1, vy=...)` (полилиния) |
| Замкнуть контур | `entity_edit_geometry(handle, closed=true)` |
| Значение LISP | `system_run_lisp("(getvar \"DIMSCALE\")")` теперь возвращает значение; ошибка LISP приходит как `ok:false` |

`spds_sheet` сам сужает длинный текст до коэффициента 0,8 и переносит графы 2, 3, 4 и 9 на две строки. Что сжато, видно в `fitted`.

На листе (`layout=...`) `spds_sheet` сам задаёт параметры печати: формат листа на носителе без полей `ISO_full_bleed_A3`, 1:1, от начала листа. Результат в `page_setup`; без этого PDF выходил A4 и обрезанным.

## 5. Требования ГОСТ (кратко)

- **Линии** (2.303, S = 0,5): контур 0,5; тонкие 0,18; невидимые штриховые 4/1,5; оси штрихпунктирные 15/2·точка·2; линия сечения разомкнутая 0,7 (штрихи 8–20).
- **Шрифт** (2.304): 2,5; 3,5; 5; 7; 10; 14; 20 мм на бумаге. Шифр 5, названия 3,5, служебные надписи 2,5.
- **Размеры** (Р 21.101 п. 5.4.2, 2.307):
  - засечки 45°, размерная линия выходит за выносные на 0–3 мм;
  - числа в мм без единиц, десятичная запятая;
  - от контура до размерной линии ≥ 10 мм, между размерными линиями ≥ 7 мм.
- **Отметки** (п. 5.4.3): метры, три знака, запятая; на планах в прямоугольнике.
- **Оси**: кружок ⌀6–12 мм, шрифт марки в 1,5–2 раза крупнее размерных чисел.
- **Штриховки** (2.306): металл ANSI31, неметаллы ANSI37, бетон AR-CONC. Сечения КЖ часто без штриховки — уточнить у руководителя.
- **Грунты** (21.302, табл. 4): `spds_soil_hatch`, ближайший стандартный образец под углом и с шагом ГОСТ; гравий и почвенно-растительный слой рисуются вручную.
- **УГВ**: синим (цвет 5), штриховой линией GOST_DASH.

## 6. Ловушки, которые остались

- Сохранять и экспортировать можно только внутри ALLOWED_PATHS. Недостающие подпапки внутри разрешённого корня создаются сами, вне его будет отказ. Обходить через `system_run_command` нельзя.
- `system_run_command` выполняет одну команду за вызов. Длинный диалог (`-PLOT`) зависает, для печати есть `drawing_export_pdf` и `batch_plot`.
- **Чертёж пользователя чужой.**
  - Не сохранять и не закрывать его без просьбы. `*` во вкладке означает несохранённые изменения.
  - В конце сказать, что изменено, вернуть исходную вкладку и удалить служебные объекты.
- Скриншот проверяет только внешний вид. Состояние чертежа проверяют `drawing_digest` и `drawing_diff_since`.

## 6а. Проверка по ГОСТ: фокусы `drawing_critique`

Работают только на чертеже с записями `ACADMCP_SPDS`, то есть с тем, что нарисовано инструментами `spds_*`. На чужом чертеже молчат.

| Фокус | Что находит |
|---|---|
| `spds_text_height` | Текст, у которого высота на бумаге (высота / M) не из ряда 2,5…20. Текст без записи на слоях СПДС проверяется по масштабам, записанным на том же листе |
| `spds_lineweight` | Вес слоя СПДС не как в наборе `spds_setup`, или собственный вес объекта вне ГОСТ 2.303 (ByLayer всегда годится) |
| `spds_axis_letter` | Запрещённая буква в марке оси или нарушен порядок: цифры слева направо, буквы снизу вверх |
| `spds_elevation_format` | Текст отметки правили руками, и он разошёлся с записанным значением (например «3.30» вместо «+3,300») |
| `spds_stamp_incomplete` | Пусты графы 1, 2, 4, 6 или 7 штампа (предупреждение) |
| `spds_outside_frame` | На листе объект выходит за рамку. В модели только объекты, пересекающие рамку |

Форма 6 (основная надпись последующих листов) пока не поддерживается. Последующие листы оформлять формой 3 без графы 8 «Листов».

## 7. Чек-лист перед сдачей

- [ ] `spds_sheet`: рамка 20/5/5/5, форма 3, графы 1–9 заполнены, «Листов» только на первом листе, `fitted` без коэффициентов < 0,8.
- [ ] `drawing_critique(focus=None)` без замечаний `spds_*`.
- [ ] `drawing_digest` без `outside_frame`, `duplicate`, `open_ends` на контурах; `text_height` пусто при заданном ряде.
- [ ] Размеры стилем `СПДС_1-M` на слое «Размеры».
- [ ] Отметки «±0,000», оси по правилам, линии разреза с марками, уклоны, выноски с точкой или стрелкой.
- [ ] Грунты заштрихованы `spds_soil_hatch`, у песка буква крупности; УГВ синим пунктиром.
- [ ] Видовые экраны: масштаб 1/M, заблокированы, лишних нет (`remove_others=True`), рамка на Defpoints.
- [ ] `spds_sheet(...)["page_setup"]["ok"]` истинно, PDF размером 420×297 (А3).
- [ ] Один итоговый скриншот листа (`space="Лист1"`, `mode="mono"`) и при необходимости окно на штамп.
- [ ] PDF (если нужен) открыт и сверен глазами.
